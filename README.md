# GitHub Actions Demo

A complete Node.js project with CI/CD pipeline integration using GitHub Actions.

## Features

- Express.js REST API
- Comprehensive test suite using Jest
- ESLint for code linting
- Prettier for code formatting
- Full CI/CD pipeline setup
- Health check endpoints
- Input validation
- Error handling

## Prerequisites

- Node.js >= 16.0.0
- npm >= 8.0.0

## Installation

```bash
npm install
